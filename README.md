# julianev.github.io

Personal website. Plain HTML and CSS — no generator, no build step, no dependencies.

Published at <https://julianev.github.io>.

## Editing

Edit `index.html` and `style.css`. Preview locally by opening the file:

```sh
open index.html
```

Push to `main` and GitHub Pages redeploys within a minute.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole site — one page |
| `style.css` | All styling; light and dark themes |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is, skipping the Jekyll build |

## Deployment

Repo settings → Pages → Build and deployment → Source: **Deploy from a branch**, branch `main`, folder `/ (root)`.
